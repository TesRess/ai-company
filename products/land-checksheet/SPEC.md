# 土地チェックシート（land-checksheet）仕様

既存の「カワムラホーム ご提案資料ポータル」（HTMLファイル1つ）に、読み取り済みの土地情報から「建てられる家の大きさの目安」「注意点」「調べるためのリンク」「お客様向けの土地紹介文の下書き」をその場で作る機能を足す。

## 誰のため

- オーナーと営業チームのメンバー。
- 使う場面: 販売図面の情報をポータルの「土地情報」に取り込んだ直後（または手入力した直後）。お客様との打ち合わせの前に、「この土地に何坪くらいの家が建つか」「気をつける点は何か」をすぐ確認し、お客様向けの土地紹介文のたたき台を作りたいとき。
- 今は、取り込み後に自分で計算し、ハザードマップなどのサイトを一つずつ開き、紹介文を一から書いている。この手間を減らす。

## 作るもの

成果物は、元のHTMLの改良版 1ファイル（`products/land-checksheet/kawamura_proposal.html`）。チームの環境への差し替えはオーナーが行う。

1. **道路情報の入力欄を追加** — 「土地情報」の各候補の入力欄に、「前面道路の方位」（北・北東・東・南東・南・南西・西・北西）、「道路の幅（m）」、「間口＝道路に接する長さ（m）」、「公道／私道」、「角地の緩和あり（役所で確認済み）」のチェックを足す。
2. **建てられる大きさの目安** — 面積・建ぺい率・容積率・用途地域・道路の幅から、建築面積の上限、延床面積の上限、平屋なら何坪まで、2階建てなら何坪まで、を㎡と坪で出す。道路の幅による容積率の制限、4m未満の道路のセットバック（下がる幅と減る面積）も反映する。
3. **注意点と駐車台数の目安** — 用途地域・道路の方位と幅・間口・法令上の制限欄の内容から、斜線制限（道路・北側・隣地）、高さの制限、接道、防火・高度地区などの注意点を短い文で並べる。駐車台数の目安も出す。
4. **調べるためのリンク** — 所在地をクリップボードにコピーしてから、重ねるハザードマップ、わがまちハザードマップ、不動産情報ライブラリ（都市計画の確認用）、Googleマップを新しいタブで開くボタン。市区町村ごとの都市計画図のURLは、自分で登録できる（この端末に保存）。
5. **土地紹介文の下書き** — 決まった文の型に土地情報を当てはめて、お客様向けの紹介文を作る（AIは使わない）。新しい「土地紹介文」欄に入り、自由に直せる。提案書の「土地紹介」ページでは、この欄があればそれを、空なら今までどおり「備考」を表示する。

画面に出す計算結果と注意点には、必ず「目安」「最終的には役所・設計担当で確認が必要」と書く。チェックシートの内容は「文章でコピー」ボタンでコピーでき、チャットや社内メモに貼れる。

### 既存の画面・項目とのつなぎ方

| 使う情報 | 既存の場所（元のHTML） | 扱い |
|---|---|---|
| 所在地・面積・用途地域・建蔽率・容積率・法令上の制限・交通・学校区 | 土地情報 `state.landInfos[i]` の `address` / `area`（例「165.29 ㎡ (約 50.00 坪)」）/ `zoning` / `coverage`（例「50%」）/ `far` / `restrictions` / `traffic` / `school` | そのまま読む。数値は文字列の先頭の数字を取り出す（既存の `firstNum` と同じ考え方） |
| 取り込みJSON | 「販売資料から土地情報を自動入力」の `PASTE_FIELDS`（物件名・所在地・土地面積㎡・価格万円・現況・地目・引渡し時期・用途地域・ガス・地勢・上下水道・建蔽率・容積率・建築条件・法令上の制限・交通・学校区・備考） | **変えない**。道路の方位・幅は今は「備考」に文章で入るので、新しい道路欄は手で入れる |
| 新しい項目 | `emptyLand()` に `roadDir`, `roadWidth`, `roadFrontage`, `roadType`, `cornerRelief`, `intro` を足す | 保存データの読み込み時は `{ ...emptyLand(), ...l }` で補われるので、古い案件もそのまま開ける |
| 取り込み時の上書き | `applyExtractedLand` は土地情報を空にしてから入れ直す | 道路欄と土地紹介文も空に戻る（別の物件の値が残らないため。今の動きに合わせる） |
| 入力画面 | `renderLandInfos()` の「土地情報 候補N」カード | 入力欄の下（「土地資料アップロード」の上）に「土地チェックシート（目安）」の枠を足す。入力を変えるとすぐ再計算 |
| 提案書の「土地紹介」ページ | 提案書作成部分の `addSection('Property Overview', '土地紹介', …)`。今は `memo` を本文に表示 | `intro` があれば `intro` を、空なら `memo` を表示。ほかのページ構成は変えない |
| 地図リンク | 既存の `openGoogleMap()`（新しいタブで開き、opener を切る） | 同じやり方でハザードマップ等を開く。撮った画面は既存の「画面を撮影して取り込む」で「土地解析」に入れられる、と案内文に書く |
| 建築面積・延床面積の計算 | マイホームロボ欄の `roboCapacity()`（面積×建ぺい率、面積×容積率） | 新しい計算は道路の幅・セットバックも見るため別に作る。マイホームロボ欄は今回は変えない |
| 端末への保存 | `kw_myhomerobo_url` など `kw_` で始まる localStorage | 市区町村の都市計画図URLの登録は `kw_cityplan_links` に保存 |

## 計算のきまり（一般的な目安の範囲）

- 坪 = ㎡ ÷ 3.30578（小数1桁で表示。既存のマイホームロボ欄と同じ）。
- **セットバック**: 道路の幅が4m未満なら、下がる幅 =（4 − 道路の幅）÷ 2、減る面積 = 下がる幅 × 間口。以下の計算はセットバック後の面積を使い、元の面積も並べて出す。間口が未入力なら減る面積は「間口を入れると表示」。
- **建築面積の上限** = 面積 × 建ぺい率。「角地の緩和あり」にチェックがあれば建ぺい率に10%を足す。
- **容積率**: 道路の幅が12m未満なら、道路の幅 × 0.4（住居系の用途地域）または × 0.6（それ以外）で出した数字と、指定の容積率の小さい方を使う。4m未満の道路は4mとして計算する（セットバックする前提）。下がった場合は「道路の幅のため 200% → 160% で計算」のように理由を出す。
- **延床面積の上限** = 面積 × 使う容積率。
- **平屋の目安** = 建築面積の上限。**2階建ての目安** = 建築面積の上限 × 2 と延床面積の上限の小さい方。
- **駐車台数の目安**（並べて止める場合）=（間口 − 1.0m（玄関までの通路分））÷ 2.5m の切り捨てと、（面積 − 建築面積の上限）÷ 15㎡ の切り捨ての小さい方。間口が未入力なら「間口を入れると表示」。
- **注意点の文**（用途地域と入力から決まった文を出す）:
  - 道路斜線: すべての用途地域で出す（住居系は勾配1.25、それ以外は1.5）。
  - 北側斜線: 第一種・第二種低層住居専用、田園住居（高さ5m＋1.25）、第一種・第二種中高層住居専用（高さ10m＋1.25、日影規制がある地域では外れることがある）。道路が南側なら「建物の北側が隣地になるので、2階北側の屋根の形に影響が出やすい」を足す。道路が北側なら「北側が道路なので北側斜線は比較的ゆるい」を足す。
  - 高さの制限: 第一種・第二種低層住居専用、田園住居は「高さ10mまたは12m（都市計画で決まる）」。
  - 隣地斜線: 上の3地域以外で出す（一般的な2階建てでは影響は小さい、と添える）。
  - 接道: 道路の幅4m未満 → セットバックの注意。間口2m未満 → 「建築基準法の接道（2m以上）を満たさない恐れ。建て替えできない土地の可能性」。私道 → 「私道の持ち分・通行や掘削の承諾を確認」。
  - 法令上の制限欄に「防火」「準防火」が含まれる → 窓・外壁の仕様に費用の影響。「高度地区」→ 自治体の高度地区の基準を確認。「景観」→ 色や形の届出を確認。「宅地造成」→ 擁壁・造成の確認。
  - 用途地域が「指定なし（市街化調整区域等）」→ 「原則として家が建てられない場合がある。必ず役所で確認」を一番上に出し、大きさの目安は出さない。
  - 毎回、最後に「日影規制・壁面後退・敷地の最低面積・条例などは自治体ごとに異なるため、役所で確認」を出す。

## やらないこと

- 販売図面からの読み取り作業の改良（ワンクリック読み取り、取り込みJSONの項目追加）。今の「プロンプトをコピー → Gemini → 貼り付け」はそのまま。
- 土地候補どうしの比較表。
- 自治体ごとの条例・日影規制・壁面後退・高度地区の数値・敷地の最低面積・がけ条例・地区計画の中身の計算。注意文で「確認が必要」と出すだけ。
- 防火地域の耐火建築物による建ぺい率の緩和、天空率、地下室・吹抜けの容積率の扱い、斜線制限で建てられる形の図や高さの計算。
- ハザードマップや都市計画図のサイトを、ツールが自動で読みに行くこと（住所から緯度経度を調べる外部サービスの呼び出しも含む）。リンクを開くだけ。
- AIによる紹介文作成。紹介文は決まった文の型で作る。
- チェックシートを提案書（お客様向けPDF）のページとして入れること。チェックシートは社内向けで、お客様向けに出るのは土地紹介文だけ。
- マイホームロボ欄の変更（道路方位・間口を土地情報から自動で入れるなど）。
- Web公開、スマホ対応、メール送信・SNS投稿などの外部送信。改良版のチームの環境への差し替え（公開）はオーナーが行う。
- 開発・テストで本物のお客様情報や物件情報を使うこと（ダミーデータのみ）。

## 完成の条件

確認は、Firebase を設定していない状態（データは端末内に保存）で改良版HTMLを開き、新しい案件にダミーの土地情報を入力して行う。数字は小数1桁（坪・㎡）で表示されること。

1. **基本の例**: 所在地「ダミー市ダミー町1丁目2-3」、第一種低層住居専用地域、165.29㎡、建ぺい率50%、容積率100%、前面道路 南・4m・公道、間口10m を入れると、次が出る。
   - 建築面積の上限 82.6㎡（約25.0坪）、延床面積の上限 165.3㎡（約50.0坪）、使う容積率は 100%（道路による制限 160% より指定の方が小さいため）
   - 平屋なら約25.0坪まで、2階建てなら約50.0坪まで
   - 駐車台数の目安 3台（間口から3台、空き地の広さから5台 → 小さい方）
   - 注意点に「道路斜線」「北側斜線（南道路なので北側の屋根に影響が出やすい）」「高さ10mまたは12m」が出て、「隣地斜線」「セットバック」は出ない
   - 「目安」「役所・設計担当で確認」の文言が見える
2. **道路が狭い例**: 1と同じで道路の幅だけ 3.6m にすると、「セットバック約0.2m、敷地が約2.0㎡減る」と出て、建築面積の上限 81.6㎡（約24.7坪）、延床面積の上限 163.3㎡（約49.4坪）になる。元の面積 165.29㎡ も並べて出る。
3. **道路で容積率が下がる例**: 第一種中高層住居専用地域、150㎡、建ぺい率60%、容積率200%、道路 北・4m、間口8m で、建築面積の上限 90.0㎡（約27.2坪）、延床面積の上限 240.0㎡（約72.6坪）、「道路の幅のため 200% → 160% で計算」と出る。駐車台数の目安は 2台。
4. **注意が強く出る例**: 間口を 1.8m にすると接道（2m以上）の注意が出る。法令上の制限に「準防火地域」を入れると防火の注意が出る。用途地域を「指定なし（市街化調整区域等）」にすると「家が建てられない場合がある」が一番上に出て、大きさの目安は出ない。
5. **未入力のとき**: 面積や建ぺい率が空なら、該当の結果は「—」になり、エラーで画面が止まらない。間口が空なら駐車台数とセットバックの減る面積は「間口を入れると表示」になる。
6. **リンク**: 「重ねるハザードマップ」ボタンを押すと、所在地がコピーされたと表示され、新しいタブでサイトが開く（貼り付けると所在地が入る）。所在地が空なら「所在地が未入力」と表示してサイトのトップを開く。設定で「ダミー市 → https://example.com/dummy-cityplan」を登録すると、所在地が「ダミー市」で始まる土地に「ダミー市の都市計画図」ボタンが出る。ツールがこれらのサイトを自分で読みに行かない（ボタンを押すまで通信しない）。
7. **土地紹介文**: 1の例で「下書きを作る」を押すと、「土地紹介文」欄に、少なくとも次の内容を含む文が入る: 「第一種低層住居専用地域」「約50.0坪（165.29㎡）」「南側の4m道路」「日当たり」「建ぺい率50%・容積率100%」「2階建てなら延床約50.0坪」「目安」。交通・学校区を入れていればその文も入る。欄はその後自由に直せる。既に文が入っているときは上書きの確認が出る。
8. **提案書**: プレビューの「土地紹介」ページに、土地紹介文が入っていればそれが、空なら今までどおり備考が出る。
9. **既存の動き**: 改良前に保存した案件（道路欄なし）を開いてもエラーにならず、ほかのページ（資金計画・マイホームロボなど）と「販売資料から自動入力」の取り込みが今までどおり動く。取り込み後は道路欄と土地紹介文が空になる。
10. **文章でコピー**: 「文章でコピー」を押すと、上の計算結果と注意点が文章でクリップボードに入る。

## 見積もり

- 作業量の目安: **5〜7日**（1〜2週間で使い始められる大きさ。分割は不要）。
  - 道路欄の追加と保存まわり: 1日
  - 計算と注意点（計算部分は画面と切り離し、ダミーデータで確かめられる形にする）: 2日
  - リンクと市区町村URLの登録: 1日
  - 土地紹介文の下書きと「土地紹介」ページの差し替え: 1日
  - 完成の条件1〜10の確認と手直し: 1〜2日
- 気をつける点: 元のHTMLは約2.1MBで、大半が埋め込み画像。改良は土地情報まわりに限り、ほかの部分は触らない。
- 次の版の候補: 取り込みJSONに道路の方位・幅・間口を足して自動で入れる、マイホームロボ欄に道路情報を引き継ぐ、チェックシートを印刷用ページにする。
