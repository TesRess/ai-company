# 土地チェックシート（land-checksheet）

「カワムラホーム ご提案資料ポータル」の改良版です。土地情報を入れると、その場で次のものが出ます。

- 建てられる家の大きさの目安（平屋なら何坪、2階建てなら何坪）
- 気をつける点（斜線制限・セットバック・接道・防火など）と駐車台数の目安
- ハザードマップなどを開くボタン（所在地をコピーしてから開きます）
- お客様向けの「土地紹介文」の下書き

出てくる数字や注意点はすべて**目安**です。最終的には役所・設計担当で確認してください。

## 開き方

改良版は 1つのファイル `kawamura_proposal.html` です。

- Windows: このファイルをダブルクリックする（Chrome か Edge で開きます）
- Mac: ターミナルで次を実行する

```bash
open products/land-checksheet/kawamura_proposal.html
```

※ 見た目の部品をインターネットから読み込むため、ネットにつながった状態で開いてください。

## 使い方

1. 案件を開き、「土地情報」に所在地・敷地面積・用途地域・建蔽率・容積率を入れる（「販売資料から自動入力」でもよい）。
2. 同じカードの「前面道路」に、道路の方位・道路の幅・間口・公道／私道・角地／二方向道路を入れる。角地の緩和を役所で確認済みならチェックを入れる。
   - 「販売資料から自動入力」で取り込むと、図面から読み取れた道路の情報もここに入ります（読み取れなかった項目は空のままなので、手で入れてください）。「角地の緩和あり」は取り込みでは入りません。
   - 取り込むと、その候補の内容は取り込んだ内容に置き換わります。土地紹介文が入っている候補へ取り込むときは、先に確認が出ます。
   - 道路の幅が4m未満で間口が空のときは、セットバック分を引かずに計算しています（目安がやや大きく出ます）。間口を入れると引いて計算し直します。
3. すぐ下の「土地チェックシート（目安）」に結果が出ます。入力を変えるとすぐ計算し直します。
   - 「文章でコピー」を押すと、結果と注意点をチャットや社内メモに貼れます。
   - 「重ねるハザードマップ」などを押すと、所在地をコピーしてから新しいタブでサイトを開きます。開いたサイトの検索欄に貼り付けてください（Ctrl＋V／Macは Cmd＋V）。
   - 「市区町村の都市計画図のリンクを登録」で、市区町村名と URL を登録すると、その市区町村の土地に「○○の都市計画図」ボタンが出ます（このパソコンのブラウザに保存されます）。
4. 「下書きを作る」を押すと「土地紹介文」に下書きが入ります。自由に直してください。提案書の「土地紹介」ページには、土地紹介文があればそれが、空なら今までどおり「備考」が出ます。

チェックシートは社内向けで、提案書（お客様向けPDF）には入りません。

## チームの環境への差し替え

改良版をチームの環境に置き換える作業は、オーナーが行ってください（このツールは何も公開・送信しません）。

## テスト（開発者向け）

ダミーデータだけを使います。リポジトリのいちばん上のフォルダで実行します。

```bash
node --test products/land-checksheet/tests/logic.test.js
```

画面の確認（ヘッドレスのブラウザで操作。Playwright が必要）:

```bash
node --test products/land-checksheet/tests/e2e.test.js products/land-checksheet/tests/e2e-v2.test.js
```

まとめて全部:

```bash
node --test products/land-checksheet/tests/*.test.js
```
