# 会社の記録

社長役は `/company` を呼ばれるたびに、ここを読んで続きから始めます。オーナーが直接書き換えても構いません。

| ファイル | 中身 | 主に書く役 |
|---|---|---|
| `status.md` | 今の段階と、進行中のプロダクト | 社長 |
| `troubles.md` | 聞き取った困りごとの一覧 | 社長 |
| `ideas.md` | 提案したアイデアと、選んだ／選ばなかった結果 | 社長 |
| `products/<名前>.md` | 各プロダクトの仕様と進み具合 | 企画（進み具合は社長） |

## 段階（`status.md` の「段階」に書く値）

`なし` → `提案中` → `仕様作成中` → `仕様確認待ち` → `実装中` → `レビュー中` → `取り込み待ち` → （完了・中止で）`なし`

## 書き方の約束

- 日付は `YYYY-MM-DD`。
- 困りごと・アイデアには番号をつける（`T-001`、`I-001`）。消さずに、状態を書き換える。
- オーナーの個人データ（メールの本文、人の名前、口座番号など）は書かない。困りごとの要約だけを書く。
