# AIカンパニー

社長・企画・エンジニア・レビューの4役のAIエージェントが、オーナーの**仕事や生活の困りごとを解決する小さなツール**を作るチームです。Claude Code の上で動き、追加の費用やサーバーは要りません。

## 使い方

Claude Code でこのリポジトリを開き、こう話しかけるだけです。

```
/company
```

社長役が困りごとを聞き取り、アイデアを2〜3案提案します。あとはこの流れで進みます。

```
/company
  └ 社長: 聞き取り → アイデア2〜3案を評価つきで提案
あなた: 1案を選ぶ            ← 確認ポイント①
  └ 企画: 仕様を書く
あなた: 仕様を確認           ← 確認ポイント②
  └ エンジニア: 実装・テスト
  └ レビュー: チェック（問題があればエンジニアに戻す）
  └ 社長: 結果を報告
あなた: 確認して取り込む      ← 確認ポイント③
```

確認ポイントでは、AIは必ず止まってあなたの返事を待ちます。途中でやめても、次に `/company` と打てば続きから始まります。

## 約束ごと

- AIがあなたの確認なしに、公開・リリース・課金・外部への送信をすることはありません。
- AIが作業中にあなたのメール・カレンダー・Notionなどの個人データを読むことはありません（`.claude/settings.json` でも禁止しています）。開発にはダミーデータを使います。
- 作るのは、あなたのパソコンだけで動くツールです。
- 同時に進めるプロダクトは1つだけです。
- エンジニアは `product/<名前>` ブランチで作業し、メインブランチへの取り込み（マージ）はあなたが行います。

詳しいルールは [`CLAUDE.md`](CLAUDE.md)、設計は [`docs/superpowers/specs/2026-11-22-ai-company-design.md`](docs/superpowers/specs/2026-11-22-ai-company-design.md) にあります。

## 中身

| 場所 | 中身 |
|---|---|
| `.claude/commands/company.md` | `/company` コマンド（社長役の進め方） |
| `.claude/agents/` | 4役の定義（`ceo` / `pm` / `engineer` / `reviewer`） |
| `.claude/settings.json` | 個人データの読み取りや公開・マージを止める設定 |
| `company/` | 会社の記録（今の状態、困りごと、アイデア、仕様） |
| `products/` | 作ったツール |
